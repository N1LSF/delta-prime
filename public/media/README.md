# Медиа главной страницы

Сюда нужно положить фоновые ассеты. Имена файлов **фиксированы** — они уже прописаны в компонентах
(`src/app/page.tsx` → `BackgroundMedia`). Пока файлов нет, секции показывают аккуратный
градиент-фолбэк (`.bg-media-fallback`), вёрстка не ломается.

## Hero (первый экран) — видео + постер

| Файл | Назначение | Рекомендации |
|------|------------|--------------|
| `hero.mp4`  | Основное видео (H.264/AAC без звука) | 1920×1080, 10–20 c, луп, ≤ ~6–8 МБ |
| `hero.webm` | То же видео в WebM (VP9) — отдаётся первым, легче | 1920×1080, ≤ ~4–6 МБ |
| `hero-poster.jpg` | Кадр-постер + фолбэк для мобильных/`prefers-reduced-motion` | 1920×1080, ≤ ~300 КБ |

Поведение: видео автоплеится (muted, loop, playsInline) только на десктопе (≥ 768px) и при
выключенном «уменьшении движения». На мобильных и при `prefers-reduced-motion` показывается
только `hero-poster.jpg`. Поверх видео — светлый scrim (`.hero-overlay`), текст hero тёмный.

## Фото услуг (опционально)

Карточки в `ServicesGrid` показывают фото, только если в `src/data/services.ts` у услуги задано
поле `image`, напр.:

```ts
{ slug: 'rental', /* ... */ image: '/media/services/rental.jpg' }
```

Без `image` остаётся icon-плейсхолдер. Рекомендуемый размер фото услуг: 800×600 (4:3), ≤ ~200 КБ.

## Советы по подготовке

- Видео без звука; оптимизировать через `ffmpeg` (CRF ~28 для mp4, `-b:v 0 -crf 33` для webm).
- Изображения — в WebP/оптимизированный JPG; для hero-фона хватает ширины 1920px.
- Светлые/спокойные кадры читаются лучше под тёмным текстом hero (поверх — светлый scrim).
